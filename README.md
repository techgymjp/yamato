# 戦艦大和 天一号作戦

艦長目線で戦艦大和を指揮し、昭和20年4月7日の米艦載機の猛攻をしのいで沖縄到達を目指すブラウザゲームです。

`index.html` をブラウザで開くだけで遊べます（Three.js は CDN から読み込みます）。

## 遊び方
- **A / D（← / →）**: 転舵。旋回は素早い
- **W / S**: 速力の増減（原速〜最大戦速）
- **マウス・クリック**: 対空ロケット弾で敵機を迎撃。長押しで連射し、照準付近の敵機を追尾する
- **Space 長押し → 離す**: 波動砲。艦首方向へ発射し、敵空母（6隻）を撃沈する
- **F**: 注排水。右舷に注水して左舷への傾斜を戻す。そのぶん予備浮力と速力が減る
- **Q / E・画面端**: 見張りの向きを変える（R で正面）

米軍機（TBM雷撃機・SB2C急降下爆撃機・F6F戦闘機）は大和を転覆させるため **左舷** に攻撃を集中してきます。
傾斜が30°に達するか、予備浮力または艦体耐久を失うと沈没します。
エンディングでは視点が艦外に移り、大和の全体を見渡せます。

## 史実に基づく要素
- 4月6日15時20分 徳山沖出撃、7日 朝霜の落伍、12時30分過ぎに攻撃開始
- 第二艦隊の編成：大和・矢矧・駆逐艦8隻による輪形陣
- 12:48 浜風沈没、14:05 矢矧沈没、14:23 大和沈没（史実の時刻を表示）
- 低い雲の下からの来襲、左舷に集中した雷撃、右舷への注水による傾斜復元、横転後の弾火薬庫誘爆
- 日没後は空襲が止む

波動砲と対空ロケット弾はゲーム独自の架空兵装です。
